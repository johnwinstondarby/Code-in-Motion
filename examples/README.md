# Examples

## Purpose

This directory contains small, non-normative examples showing how to invoke and integrate CiM.

## Owns

- Minimal host markup examples
- Minimal synthetic experience demonstrations
- Integration snippets that use public interfaces

## Does not own

- Normative contracts
- Production source code
- WordPress plugin implementation

## Allowed dependencies

Examples use released or branch-current public APIs only.

## Prohibited dependencies

Examples must not establish undocumented behavior that conflicts with `docs/` or component READMEs.

## Verification

Examples are kept executable or structurally testable as the public interfaces evolve.
